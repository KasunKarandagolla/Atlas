## Current implementation truth

The repository contains a real, durable market-to-decision pipeline and a separate set of later research/lifecycle features. Their presence does not make them one connected workflow. In particular, the frozen production receipt still disables the S47 research agent; Decision Brief, S47 research memory and the S48 lifecycle projection have no unified runtime-to-GUI path. S49 can safely fix observer integration and optional effort handling, but it cannot activate the proposed discretionary selector or claim provider capability without a separately accepted amendment and external qualification.

The retained S46–S48 manifests were parsed and their recorded artifact paths checked. Historical source digests resolve at their respective commits. The S47 and S48 manifests refer to `secret_scan_delivery.json` artifacts that are absent from the checked-out evidence directories, and the S47 source-file checksum describes its S47 historical version rather than the later S48 version. This is an evidence-index integrity limitation; it is not evidence of a secret. S49 records its own evidence paths and hashes in the adjacent manifest.

## S49 implementation delta and integration disposition

The first part of this register describes the verified S48 starting point. The legacy hash behavior is separately asserted with the selected S49 setting.
