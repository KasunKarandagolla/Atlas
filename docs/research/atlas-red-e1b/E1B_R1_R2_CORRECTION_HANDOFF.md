## Scope and result

This correction changes only the E1B diagnostic output producer and its evidence. It does not change S1/S6 policies, strategy objectives, the coordinator, frozen authority files, or production readers. The input cohort, windows, checksum-verified source archives, source calendar, and missing rows remain fixed.

R1 now records the current descriptive precursor separately from a deterministic setup-event ID and the setup ID/cutoff/side/ref that owns an M15 trigger opportunity. The previous setup owns the H1 boundary's final opportunity; a newly observed setup cannot replace its direction. Every matching bar predicate remains visible, while `s1_first_trigger_event` is set only for the first match per setup ID. Current-source gaps always remain `SOURCE_MISSING`; an active setup also requires a present, contiguous previous M15 bar. Repeated SETUP rows are state observations, not independent setups or trades.

R2 replaces typed `RawObservationV2` construction with an explicit research-only `ResearchBar`. Stable source identities bind the verified archive SHA and CSV member row index; reconstructed archive receipt time remains `UNKNOWN_NOT_CAPTURED_AT_ACQUISITION`. The replay clock is separate: default completed-bar availability is close +5 seconds, +30/+60-second sensitivities are explicit helper options, and derived-feature availability adds at least one second after all latest source dependencies. Exact-close S1 outputs are explicitly zero-lag descriptive bar predicates and are not replay-visible at that cutoff. No live or production observation is emitted.
